Loading AEW Dynamite Television Ratings

library(tidyverse)
library(jsonlite)

# Read the JSON without letting jsonlite guess the structure
ratings <- fromJSON("https://trnbckl.net/ratings.json", simplifyVector = FALSE)

# Helper: turn JSON nulls into NA so every record has the same shape
null_to_na <- function(x) map(x, \(v) if (is.null(v)) NA else v)

# Weekly episode records: show, air date, viewers, P18-49 rating, code, note
weekly <- ratings$weekly |> 
  map(null_to_na) |> 
  map(\(x) tibble(
    show        = x[[1]],
    air_date    = x[[2]],
    viewers     = x[[3]],
    demo_rating = x[[4]],
    code        = x[[5]],
    note        = x[[6]]
  )) |> 
  list_rbind() |> 
  mutate(
    air_date    = ymd(air_date),
    viewers     = as.numeric(viewers),
    demo_rating = as.numeric(demo_rating),
    year        = year(air_date)
  )

dynamite <- weekly |> 
  filter(show == "Dynamite")

# Save a CSV copy so the analysis doesn't depend on the live site
write_csv(dynamite, "dynamite_weekly.csv")

# Annual averages, if she wants them for checking her own calculations
annual <- ratings$annual |> 
  map(null_to_na) |> 
  map(\(x) tibble(
    show     = x[[1]],
    year     = x[[2]],
    metric   = x[[3]],
    value    = as.numeric(x[[4]]),
    episodes = x[[5]],
    note     = x[[7]]
  )) |> 
  list_rbind()

Regression Analysis: Accounting for Changes in Viewership Over Time

Professor Willis recommended using regression to see whether CM Punk’s status was associated with Dynamite’s viewership after accounting for changes over time. Unlike the ANOVA and Tukey tests, this analysis will include both the CM Punk periods and the passage of time. I want to see whether the differences we found earlier remain after considering the show’s overall viewership trend.

punk_comparison <- punk_comparison |>
  mutate(
    weeks_since_start = as.numeric(air_date - min(air_date)) / 7,
    period = factor(period, levels = c("Active", "Absent", "After"))

punk_regression <- lm(
  viewers ~ weeks_since_start + period,

Making Sense of the Regression Results

The regression changed how I looked at Dynamite’s viewership numbers. Earlier, we found that Dynamite averaged about 293,166 fewer viewers after CM Punk left AEW compared with his active periods. However, once I accounted for time, that difference dropped to about 101,545 viewers. The difference was still statistically significant (p < 0.001), but it wasn’t nearly as large as it first appeared.

Another thing that stood out was the overall decline in ratings. The model estimated that Dynamite lost approximately 1,278 viewers per week, even after accounting for Punk’s status. Meanwhile, the difference between his active and absent periods was only about 7,804 viewers after accounting for time, and that wasn’t statistically significant (p = 0.6974).

The model explained about 67% of the variation in weekly viewership. What I’m taking away from this is that AEW’s ratings were affected by a broader downward trend. While viewership was significantly lower after Punk left, these numbers alone don’t prove his departure was responsible. There’s more to the story than whether Punk was with the company.
